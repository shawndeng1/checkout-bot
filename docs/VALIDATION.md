## Verified behaviors

- Production Electron app opens and renders the dashboard.
- Renderer has no Node `require`; the bridge exposes only snapshot, command, and subscription methods.
- Task groups and tasks are created and persisted.
- Tasks can be edited, duplicated, started, stopped, and deleted through the UI.
- Mock inventory availability updates task status, pauses for approval, and completes simulated checkout.
- Inventory/state events and checkout completion are visible in the log viewer.
- Group, task, and terminal status survive closing and relaunching Electron.
- Profile and HTTP/SOCKS5 proxy forms support creation, editing, and deletion.
- Preference controls persist concurrency, notice settings, and log detail.
- Vite development renderer opens with the preload bridge and no observed page errors.
- Core tests verify every state-machine edge, cancellation in monitoring/approval/retry waits, queue cancellation, concurrency changes, duplicate prevention, retry bounds, checkout failure, restart run IDs, persistence, interruption recovery, cascading deletion, malformed inputs, proxy syntax, and deterministic mock inventory events.

Screenshots were generated by Playwright at `test-results/desktop-tasks.png` and `test-results/desktop-dashboard.png` and visually inspected. Tests use isolated temporary data directories that are removed on completion.

## Limitations

- Runtime launch and GUI tests were executed on macOS. Windows and Linux validation is still required.
- No signed installers, automatic updater, or distribution artifacts are included.
- SQLite is exported synchronously as a complete file; large workspaces need incremental storage in a worker and explicit power-loss durability guarantees.
- Snapshot events expose 500 recent logs/runs; logs are capped at 10,000 events globally. History pagination is future work.
- Profile/proxy groups are persisted names rather than independent group entities.
- Completion notices are in-app; proxy connections are not tested or used by the mock adapter.
- No live retailer traffic, real purchasing, sensitive credentials, or security-bypass functionality exists.

Build output includes harmless Rollup warnings about annotation placement in the Zod dependency. They do not fail the build. Earlier validation runs exposed defects in persistence updates, foreign-key reset after SQL.js export, profile edit payloads, and selector labels; those were fixed before the passing final runs.
